# AI真人口播视频生成设计说明

**状态：** 已确认  
**日期：** 2026-08-31  
**目录：** `video-ai-talking/`

独立本机 Web：用户克隆源码、启动页面，填入自己的阿里百炼 VideoRetalk Key（对口型必填），以及可选的百炼 CosyVoice / 火山 TTS 与 DeepSeek Key；引用一段口播真人视频（不用自己说话）、写或生成一条口播文案、选一套皮肤，生成本地 9:16 MP4。字幕段可整屏切到视频素材。

不引入数据库、Redis、用户自备对象存储、Docker、License 或商业化。

## 成功标准

1. Windows / macOS / Linux 用同一组 Node 命令即可打开页面。
2. 未配置时页面明确引导；配置后能完成「参考视频 + 一条文案 + 一套皮肤 → 一条 MP4」。
3. 链路固定 `voice → lipsync → video`。指纹未变且对口型文件仍在时，重新生成只重跑 FFmpeg。VideoRetalk 异步轮询默认 10 秒一次、最多 20 分钟。
4. 工作台显示任务进度，可预览、下载；失败后整任务重新生成。
5. 可用 DeepSeek 生成 1 条文案，也可手写。AI 生成按用户选择的成片秒数（15 / 30 / 45 / 60，或自定义 10–60）控制口播字数。
6. BGM 与视频素材可选；切入素材时原声丢弃。
7. 仓库不含 Cookie、API Key、用户素材、人脸参考视频或成片。

## 技术

| 用途 | 选择 |
|------|------|
| 页面 | Vite + React + TypeScript |
| 本机服务 | Hono（Node） |
| 配音 | 火山引擎 TTS HTTP，或阿里百炼 CosyVoice |
| 对口型 | 阿里百炼 VideoRetalk；素材走官方临时上传 |
| 文案 | DeepSeek `deepseek-chat`，只生成 1 条 |
| 成片 | 本机 `ffmpeg` / `ffprobe`，固定 9:16 `cover` |
| 存储 | `data/` JSON + 文件；素材以本机路径引用 |

端口：开发时页面 `127.0.0.1:5175`、API `127.0.0.1:8789`。生产 `npm run build && npm start` 后，页面和 API 都在 `127.0.0.1:8789`。一次 1 条成片。同时只跑一个任务。

密钥只在浏览器 `localStorage`（`vat.config`）。任务 JSON 不含密钥。配置用 modal：配音（火山 / 百炼 CosyVoice）和对口型（百炼 VideoRetalk）分开填写；出片时在配音区选一家 TTS。

## 界面

顶栏 + 分区：① 口播真人视频 / 视频素材（可选，独立面板） / ② 配音 / ③ BGM / ④ 文案 / ⑤ 模板。成片进度在工作台内，历史成片在「成片库」。口播真人视频的选用会写入 `vat.workbench`，刷新后仍停在①。

文案在④直接改标题和字幕段。每句右侧是画面格：默认口播人，点选或从「视频素材」面板拖入。模板单选，默认「纯白」；可开关「显示标题 / 显示字幕」，影响预览和成片画面，不影响口播。

## 不包含

登录、多租户、商业化、门店 / 商品 / 选题库、M × N 批量、剪映草稿、HeyGem、画中画、用户自备 OSS、节点重试、模板编辑器、采集他人视频。
