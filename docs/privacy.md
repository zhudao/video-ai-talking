# 隐私说明

AI真人口播视频生成在你自己的电脑上运行。

- DeepSeek、百炼配音、百炼对口型和火山 TTS 凭证只保存在当前浏览器的 `localStorage`（键名 `vat.config`）
- 任务记录、配音音频、对口型中间片和成片保存在本机 `data/` 目录
- 引用的图片 / 视频仍留在原路径，索引只记本机路径
- 页面请求会发到本机 API（开发默认 `127.0.0.1:5175` 代理到 `8789`，生产默认 `127.0.0.1:8789`）
- 你主动触发生成时，本机会调用 DeepSeek / 火山 TTS / 阿里百炼 CosyVoice，并把参考视频和配音上传到阿里百炼官方临时存储（`oss://`，约 48 小时）供 VideoRetalk 使用
- 视频素材和 BGM 只在本机 FFmpeg 合成，不会上传到百炼
- 本项目没有账号系统，也不会把密钥或成片发到第三方分析平台

清除浏览器站点数据会丢掉配置。删除 `data/` 会丢掉任务和成片记录，不会删除你本机原来的素材文件。
